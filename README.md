# VPS: Ubuntu + Nginx + Netdata

Учебный pet-проект: развёртывание веб-сервера и системы мониторинга на VPS.
Цель — освоить базовое администрирование Linux

## Что сделано
- Арендован VPS, выбрана ОС Ubuntu 22.04.5 LTS.
- Подключение по SSH (ssh root@X.X.X.X, аутентификация по паролю). 
- Установлен и запущен веб-сервер Nginx, проверено: отдаётся дефолтная страница
  «Welcome to nginx!», curl -I -> 200 OK.
- Установлен Netdata (мониторинг), графики просмотрены.
- Ограничен доступ к Netdata: служба привязана к 127.0.0.1,
  чтобы веб-интерфейс не был доступен из интернета.

## Стек
Ubuntu Server - Nginx - Netdata - systemd - SSH

## Чему научился (применял на практике)
- Подключаться к серверу по SSH.
- Устанавливать пакеты через apt.
- Управлять службами через systemctl (проверка статуса).
- Смотреть занятые порты (ss -tulpn).
- Проверять состояние файрвола (ufw status).
- Понимать роли: Nginx — веб-сервер, Netdata — мониторинг.
- Менять конфиг службы (/etc/netdata/netdata.conf`) и проверять результат.
